# 固定计算与分析口径

## 交易计算

- 买入、定投、转换转入：增加已确认份额，成本为成交金额加手续费。
- 卖出、转换转出：按移动加权平均成本减少份额。
- 卖出收益优先使用实际到账，其次成交金额，最后才使用份额乘确认净值减手续费估算并报警。
- 待确认交易不改变当前已确认份额和成本。
- 现金分红计入已实现现金流，不减少份额。
- 已作废交易不参与计算。
- 回本所需涨幅为剩余亏损除以当前市值。

## 固定报警

转换记录不成对、卖出缺到账金额、止盈标签与实际收益矛盾、七日内至少三笔确认买入、无减仓行为的再平衡、无边界的回撤加仓，以及疑似重复交易。

## 技术面

关联ETF使用前复权日K，量能使用ETF成交额。计算MA5/10/20/60、5/10/20日收益、RSI14、20/60日高低点和成交额倍数。没有唯一关联ETF时只分析基金净值，不分析放量。

投资判断属于不确定决策，计算正确不代表未来收益确定。
